# Final Project - PPW

Deskripsi singkat
-----------------
Proyek ini adalah aplikasi/website statis yang dibangun menggunakan HTML, CSS dan JS sebagai bagian dari tugas akhir mata kuliah PPW. Proyek menampilkan antarmuka pengguna yang responsif dan rapi untuk kebutuhan Final Project.

Fitur
-----
- Halaman beranda dengan tata letak responsif
- Navigasi sederhana antar halaman (jika ada)
- Styling konsisten menggunakan CSS (termasuk responsivitas untuk mobile)
- Struktur file yang mudah dipahami dan dikembangkan
- Menggunakan manipulasi DOM untuk menyimpan data sementara pada website

Demo / Preview
--------------
- Untuk melihat proyek secara lokal, buka `index.html` di browser.

Struktur proyek
---------------
- index.html
- program.html
- layanan.html
- tentang.html
- script.js
- login.html
- register.html
- css/
  - styles.css
- assets/
  - img/
  - logo/

Teknologi
--------
- HTML5
- CSS3
- Javascript ES6

Cara menjalankan (lokal)
------------------------
1. Clone repositori:
   git clone https://github.com/MFSA01/Final-Project-PPW.git
2. Masuk ke folder proyek:
   cd Final-Project-PPW
3. Buka `index.html` langsung di browser
